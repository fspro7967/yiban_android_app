## 步骤

每一步写：谁操作 → 点什么 → 屏幕应出现什么 → 讲解词 → 出问题时的备用方案。

| # | 环节 | 谁操作 | 操作 | 屏幕应出现什么 | 讲解词（要点） | 备用方案 |
| - | ---- | ------ | ---- | -------------- | -------------- | -------- |
| 1 | 首页 | | 打开颐伴 | 首页：问候语、下一条提醒、提醒/记录/统计/设置四个入口、右上角"同步"按钮 | 给老人用的首页只放最常用的东西，字大、按钮大 | — |
| 2 | 配对 | | 设置 → 输入 6 位配对码 | 配对成功提示 | 手机和云端配对，社区医生在看板上能看到这位老人 | 已提前配好，口头说明并展示"已配对"状态 |
| 3 | 建提醒 | | 提醒 → 新建 → 选模板"吃药" → 设时间 | 提醒列表多一条 | 内置吃药、测血压、复诊、喝水模板，少打字 | — |
| 4 | 到点提醒 | | 等第 0 步建好的提醒到点 | 全屏提醒页亮起 + 响铃 + 语音播报 | 锁屏也能亮屏，离线也能播报 | 来不及等就手动把提醒时间改到 1 分钟后 |
| 5 | 确认 | | 点"✓ 我已吃好" | 状态变"已完成"，出现 5 秒撤销条 | 点错了 5 秒内能撤销 | — |
| 6 | 稍后再提醒 | | 另一条提醒点"稍后 10 分钟" | 提示"10 分钟后再提醒你" | 老人手头有事可以晚点再吃 | — |
| 7 | 云端对照 | | 切到电脑看板 | 看板上这条提醒变"已确认" | 家属和医生在看板上实时看到 | 断网则跳到第 10 步讲补传 |
| 8 | 记录 | | 记录 → "我喝了一杯水" | 喝水格子 +1，首页同步角标变化后归零 | 喝水、睡眠、活动一键记录，自动传云端 | — |
| 9 | 统计 | | 统计页 | 7/30 天完成率（⏳ 趋势图等 F1-6） | 家属能看出这周是不是越来越差 | — |
| 10 | 断网补传 | | 下拉通知栏关掉网络 → 确认一条提醒、记一杯水 → 打开网络 | 首页出离线提示条，同步角标显示 2 → 联网后降到 0 | 电梯、地下室断网也不丢，联网自动补传 | 网络开关不好操作时改用飞行模式 |
| 11 | 升级通知家人 | | 一条提醒不操作 | ⏳ 2 分钟横幅加强、15 分钟"已通知家人"并拨号（等 F1-1、X-1） | 老人没反应时逐级升级，最后自动通知家人 | 现场时间不够：放升级链录屏 |

| 13 | 外设板 | | 板子卡片 / 按板子确认键 | ⏳ 提醒时板子亮灯、按键确认（等 B2-5、B2-6、B1-5、B1-6） | 手不方便时直接按床头板 | 用 `fake_board.py` 演示 |
